# Calculadora Custo Energia Estufa
## Descrição do Problema
Faz o cálculo do custo total de energia elétrica utilizada por aquecedores em uma estufa agrícola com base na potência, tempo de uso e tarifa.
## Requisitos
- Calcular consumo em kWh
- Aplicar desconto para uso noturno
- Somar o custo final
## Exemplo de Uso
Entrada: Potencia 2000W, Horas 5, Tarifa 0.85, Noturno True
Saída: R$ 4.25
